How it works

From upload to verified repair in minutes

01

Connect a repo

Paste a GitHub URL or drop a ZIP. Guarded ingestion clones into an isolated working copy — your origin is never mutated.

02

Run the full audit

Pick static_only, llm_only, static_llm or full repoverix. Every stage persists as an AnalysisRun — nothing silently skipped.

03

Read the evidence

Open a finding: severity, confidence, location, and the ordered chain from untrusted source to dangerous sink.

04

Ship the verified fix

Generate a minimal patch, verify it in Docker against your tests, download the Markdown report. Done.
